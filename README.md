# 婴儿食物更多配方 / More Baby Food Recipes

一个适用于 RimWorld 1.6、需要 Biotech DLC 的轻量 XML Mod。

## 功能

- 允许原版“制作婴儿食品”配方使用生肉。
- 允许原版“批量制作婴儿食品”配方使用生肉。
- 保留原版配方已有的植物性食物和动物产品选项。
- 不改变制作地点、工作量、产量、营养、保质期或贴图。
- 不添加或覆盖任何原版资源文件。

## 安装

将整个 Mod 文件夹放入 RimWorld 的 `Mods` 目录，然后在 Mod 管理器中将它放在 Core 和 Biotech 之后启用。

## 兼容性

本 Mod 通过 PatchOperation 修改 `Make_BabyFood` 和 `Make_BabyFoodBulk`，而不是复制完整的原版 RecipeDef，以减少与游戏更新及其他 Mod 的冲突。

依赖：

- RimWorld 1.6
- Biotech DLC

A lightweight XML mod for RimWorld 1.6 with the Biotech DLC. It allows raw meat in the vanilla baby food and bulk baby food recipes while leaving all other behavior and assets unchanged.
