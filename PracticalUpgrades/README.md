# Practical Upgrades / 实用强化

适用于 RimWorld 1.6。此版本为原版工具柜加入三级顺序升级；启用 Odyssey 时，也为原版逆重引擎加入三级升级，同时保留原建筑 Def，不新增重复建筑。

逆重引擎升级会逐步把重力场扩展器、小型推进器和大型推进器的连接上限恢复至原版的 6、4、6。每次升级还增加 1000 W 内置发电，并解锁容量逐级提升的逆重能量。能量五天充满，起飞时可自动抵消 25%、50% 或 75% 的实际化合燃料消耗。

三个升级模块均具有独立物品贴图。工具柜完成每一级升级后，会显示对应的完整强化外壳：I 级保留机械工具与普通部件特征，II 级突出精密计量和铀动力组件，III 级使用人格核心协调结构。各级仍沿用原版工具柜的双端柜体轮廓、四方向旋转和连接方式。

工具柜的信息卡会列出当前等级以及单台提供的工作速度、材料回收率和品质提升概率。受影响工作台的信息卡会显示材料回收与品质提升的合计值、逐台来源和触发条件；原版“工作速度系数”条目继续负责显示最终工作速度及其影响来源。

由于所有升级等级仍属于同一个原版工具柜建筑，模组会替换原版按建筑定义合并来源的说明逻辑，改为按实际升级等级分组。不同等级的工具柜连接同一工作台时，会分别显示各自的名称和真实加成。

## 使用方式

### 工具柜

1. 完成“模块化工具系统”研究（前置：制造）。
2. 在精密装配台制作对应等级的升级模块。
3. 选中工具柜并点击“安装……”；建造者会搬运模块并完成安装。
4. 必须依次安装 I、II、III 级模块。取消升级会清除本次安装进度，但不会消耗模块。

### 逆重引擎（需要 Odyssey）

1. 检查原版逆重引擎，并依次完成基础、标准和高级逆重科技。
2. 一级和二级模块在机械加工台制造，三级模块在精密装配台制造。
3. 选中逆重引擎安装对应模块；模块必须按顺序安装。
4. 一级开始显示逆重能量条。默认在起飞时自动使用能量，也可以通过引擎命令关闭自动使用。

逆重引擎的信息卡会显示当前升级等级、三类设施连接上限、内置发电、逆重能量容量与充能速度，以及单次起飞的最大燃料抵消比例。旧存档中已经超过新初始上限的设施会暂时保留连接，信息卡显示的也是当前实际允许上限；拆除后，上限会逐步回落到对应等级的正常值。

“模块化工具系统”在研究树中位于“制造”之后的独立空位。三种逆重引擎模块则分别由原版“基础逆重科技”“标准逆重科技”和“高级逆重科技”直接解锁，并显示在对应研究项目的解锁内容中。

## 数值

| 状态 | 单台工作速度 | 单台材料回收 | 单台品质偏移 |
| --- | ---: | ---: | ---: |
| 原版 | +6% | — | — |
| I 级 | +10% | — | — |
| II 级 | +15% | 5% | — |
| III 级 | +25% | 10% | 10% |

两台满级工具柜连接同一工作台时合计提供 +50% 工作速度、20% 材料回收率，以及 20% 概率使有品质的成品向传奇方向提升一级。传奇品质不会继续提升。

材料回收仅作用于普通材料（Stuff）、零部件和高级零部件；食物、药物、尸体、有品质的装备原料与手术配方不会回收。回收物作为额外产物掉落，不会在原料消耗前与原料堆叠。

## 依赖与安装

- 需要 Harmony。
- 工具柜升级不要求任何 DLC；逆重引擎升级仅在启用 Odyssey 时加载。
- 将 `PracticalUpgrades` 文件夹放入 RimWorld 的 `Mods` 目录，在模组列表中置于 Harmony 之后。

源码位于 `Source/PracticalUpgrades`，Release 编译结果位于 `Assemblies/PracticalUpgrades.dll`。
